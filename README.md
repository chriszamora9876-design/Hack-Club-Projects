# Hack-Club-Projects
projects for hack club

Wanted to see how hard it was to actually design a pcb and turn it into a functioning project (turns out it was hard to learn).
I decided to stray away from the design by routing the PCB in a unconventional but unique way, along with defiantly doing a different case design.
I aimed for a NYC theme on top of the case first because I love the city, and second because I love modeling skylines (even on Desmos).
